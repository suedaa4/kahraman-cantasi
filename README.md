# 🎒 Kahramanın Çantası (Envanter Sistemi)

Bu proje, saf **JavaScript** kullanılarak geliştirilmiş, yazılıma yeni başlayanlar için temel dizi (array) metotlarını ve fonksiyon mantığını kavramayı amaçlayan küçük bir algoritma alıştırmasıdır.

## ⚔️ Özellikler
* Çantaya dinamik olarak yeni eşyalar ekleme (`.push()`)
* Çantadaki tüm eşyaları sırasıyla ve sıra numarasıyla listeleme (`.forEach()`)
* Çantadan belirli bir eşyayı (örneğin kullanılan bir iksiri) silme/çıkarma (`.filter()`)

## 🛠️ Öğrenilen Temel Kavramlar
* **Diziler (Arrays):** Verileri bir liste halinde tutma.
* **Arrow Functions (`=>`):** JavaScript'te modern ve kısa fonksiyon yazımı.
* **Filtreleme Mantığı (`!==`):** Bir listeden belirli elemanları ayıklama.

---

## 💻 Nasıl Çalıştırılır?

Projeyi kendi bilgisayarınızda test etmek için bir terminal açıp şu komutu yazmanız yeterlidir:
```bash
node app.js
```
